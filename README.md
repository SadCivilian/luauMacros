# luauMacros

Simple macro system as a Roblox Studio plugin for the Luau language.

## Functionalities

After installing the plugin, you can add certain keywords for your macros, which work globally. While editing any script and not in a comment line, typing the macro keyword will automatically make it expand to the text of your choosing once you press space.
